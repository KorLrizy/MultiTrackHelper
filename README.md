# MultiTrackHelper（多轨道助手）

当前版本：**2.0.0-alpha**（目标游戏 v3.3.1）。

这是重构完成后的 Alpha 预发布版本，已完成离线验证，**尚未完成游戏内验收**。请使用关卡副本测试。改动、验证边界与测试清单见 [重构交付说明](REFACTOR_STATUS.md)。

公开仓库从此版本的最终源码快照开始，不包含旧实现的提交历史。历史版本 Release 仅为更新记录，其标签指向公开快照，GitHub 自动生成的源码下载不代表对应旧版本源码。

A Dance of Fire and Ice（冰与火之舞）编辑器模组：把 [AdofaiMappingHelper](https://github.com/Sprout34/AdofaiMappingHelper) 中的"多轨道"功能抽成独立模组，并做了若干改进。基于 UnityModManager + Harmony。

## 功能

在关卡编辑器事件栏新增一个 **Multi Track Helper** 标签页（位于最右侧）：

- **生成轨道（Create Track）**：把一段地砖批量转换成轨道装饰（AddObject），支持
  - 分布式 / 集中式两种布局（集中式可整体旋转）
  - 蓝红双星球装饰 + 星球随轨道运动动画
  - 深度递增、视差渐变
  - 自动继承原轨道图标（蜗牛/兔子/传送门等）
- **生成动画（Create Animation）**：对带指定 tag 的轨道装饰批量生成 MoveDecorations 出现 / 消失动画，支持分布式（逐砖） / 集中式（按 BPM 对齐角度偏移）两种时间分布。

## 相比原版的改进

1. **同 tag 幂等重建**：新增"重建前清除同标签旧结果"开关（默认开）。改参数后直接再点"创建"即可覆盖旧结果，不必反复 Ctrl+Z。tag 留空时只清理默认的 `_BluePlanet` / `_RedPlanet` 星球。
2. **随机种子**：动画的随机偏移支持固定种子（勾选"使用随机种子"后填种子值），结果可复现、可微调；不勾选则与原版行为一致。
3. **自定义星球颜色与标签**：星球颜色不再硬编码蓝/红，可在面板上自选（星球轨迹颜色与星球颜色相同，不透明度 100%）；星球标签可自定义（蓝/红各一个输入框，留空则沿用默认标签 `_BluePlanet` / `_RedPlanet`；主标签非空时默认仍为 `<tag>_BluePlanet` / `<tag>_RedPlanet`，避免多批星球互相干扰）。
4. **边界修复**：只选 1 块地砖时视差插值不再产生 NaN；从第 0 块地砖开始做集中式消失动画时不再数组越界崩溃。

原版其余功能（魔法图形、歌词、动态装饰等）仍留在 MappingHelper 中，本模组与其**可共存**（事件类型 ID 810，与 MappingHelper 的 801 不冲突）。

## 构建

依赖：Visual Studio MSBuild（含 .NET Framework 4.8 目标支持）。

```bash
cd MultiTrackHelper
MSBuild.exe MultiTrackHelper.csproj -p:Configuration=Release
```

- 引用路径由 `$(GameDir)` 属性驱动，默认 `D:\steam\steamapps\common\A Dance of Fire and Ice`，其他安装位置用 `-p:GameDir="..."` 覆盖。
- 本机未装 4.8 targeting pack 时，csproj 用 `FrameworkPathOverride` 指向系统 4.8 运行库编译；已装的可自行覆盖。
- 构建成功后自动复制到 `$(GameDir)\Mods\MultiTrackHelper\`（`-p:DeployToGame=false` 关闭）。

## 安装

将 `MultiTrackHelper_v2.0.0-alpha.zip` 拖入 UMM 的 Mods 页面安装；也可以解压后把 `MultiTrackHelper` 文件夹放进游戏 `Mods` 目录，内含：

```
Mods/MultiTrackHelper/
├── Info.json            # UMM 清单
├── Localizations.json   # 英 / 简 / 繁中文本（其他语言回退英文）
├── MultiTrackHelper.dll
└── MultiTrackIcon.png
```

启动游戏后在 UMM 设置里启用 MultiTrackHelper。

### 生成动画（给假轨道加出现/消失动画）

1. 先用"生成轨道"生成假轨道，**记住当时填的 tag**（留空则为自动标签 `_MultiTrack`）。
2. 切到"生成动画"，tag 填与轨道相同的值（**留空 = 直接作用于自动标签的假轨道**）。
3. 选动画类型（消失/出现）与参数；"效果起始方块"用于错位对齐（填 0 = 动画与轨道一一对应，-1 = 动画作用到前一块）。
4. 选中砖块或设范围 → 创建：为每块假轨道生成 MoveDecorations 动画事件。

"生成动画"只重建动画事件：**轨道装饰、星球及其环绕动画不会被删除或改动**；同 tag 的旧动画事件会被替换，可反复调整参数重新生成。

## 插入 BPM 倍频

面板的"轨道功能"里切换到"插入bpm倍频"，用于给一段轨道精确插入 SetSpeed(×倍率) 事件：

- **目标总角度**：度与拍子互转（180° = 1 拍），该值不读取轨道，而是作为执行修改的目标参考。
- **实时捕获**：默认关闭。打开后才读取选中轨道上的倍频器，并在选中砖块变化/重新打开面板时自动同步；关闭时面板保持手动输入，不做任何自动读取。区间在捕获时确定后不再随编辑器选中变化（改区间请重新捕获一次）；目标总角度标签上的 `[起始..结束]` 会显示当前区间。
- **位置**：度与砖块互转。度 = 从选中轨道第一块砖到该倍频器所在砖"进入时"的累计角度；砖块 = 事件所在的 floor。
- **数值**：bpm 与倍互转。bpm = 该位置当前生效 BPM × 倍（当前 BPM 已计入该砖之前的所有 SetSpeed 事件）。绝对 BPM 型事件的倍按 `bpm / 当前BPM` 反推。
- 开启实时捕获后，选中轨道会自动读取区间内已有的倍频器（**绝对 BPM 型与 ×倍率型都读**）并同步到面板；**超过 25 个时报"选中轨道超过限制"，且不更新面板**。
- **删除倍频器** / **添加倍频器**：逐行增删。删除只作用于"添加倍频器"加出来的行（捕获自轨道的行不会被删），从最新添加的一行删起。
- **创建**把各行写入关卡（已存在的同砖事件就地修改并**保留其原本的 BPM/倍率类型**，没有的新建为 ×倍率型），整体处于一次撤销作用域内。
- **锁定**：每个倍频器下方有一个锁定开关。锁定的行视为已知、数值固定；未锁定的行参与"计算"。若把所有行都锁上，会自动解开最后面那一行的锁定（优先解非基准行）。
- **计算 → 创建 两段式**：主按钮默认显示"计算"。设好目标总角度与各行锁定状态后点"计算"，按目标求出未锁定行的数值（恰好一个未锁定行 → 精确反解；多个未锁定行 → 保持它们当前值的相对比例整体缩放，二分求解；目标低于"第一个未锁定倍频器之前那段"的贡献时无解并提示）；计算成功后按钮变成"创建"，再点一次才真正写入关卡，写完后自动变回"计算"。任何输入改动（含添加/删除行）都会让按钮回到"计算"。新增的行默认落在区间末尾。

数值为 0 的行在创建时会被跳过。

## 轨道尺寸变化（移植自 MappingHelper）

面板的"轨道功能"里切换到"轨道尺寸变化"，在作用范围内逐砖把"起始值 → 结束值"按缓速曲线插值，写入对应的轨道设置事件：

- **轨道位置大小范围** → PositionTrack 的 `scale`（真轨道大小）。
- **轨道位置透明度范围** → PositionTrack 的 `opacity`（真轨道透明度）。与上一项共用同一条 PositionTrack 事件，两块砖不会互相覆盖。
- **星球半径大小范围** → ScaleRadius 的 `scale`（星球半径大小；它会等比改变地砖间距，幅度大时假轨道需要配合"同步大小"）。
- **缩放行星范围** → ScalePlanets 的 `scale`（目标为全部行星）。
- **缓速**：作用在"起始 → 结束"的插值曲线上，不是单条事件的动画时长。
- 四条范围各自独立，只写被勾选的那些；数值与上游一致默认为 100→100 且默认勾选。一条都没勾就点"创建"会提示"请先启用至少一条范围"。
- 重复"创建"幂等：每次先清掉作用范围内各砖上同类型的事件再重建——**包括你手动放的** PositionTrack / ScaleRadius / ScalePlanets。想保留原有事件，就先取消勾选对应的那条范围。

## 粘贴时同步速度（跨关卡搬运多轨道）

面板新增"粘贴时同步速度"开关。开启后：

- 轨道/星球动画/事件的"分布方式"自动改为集中式并锁定（跨关卡粘贴要求整批事件挂在一块砖上）。
- **复制**（Ctrl+C 多轨道锚点砖）时：记录源关卡在该砖的 BPM；如果这批多轨道此前是"分布式"创建的（事件分散在多块砖上），会**自动就地转换为集中式**——事件的 floor 归并到复制砖，`angleOffset`/`duration` 按两砖之间的角度数据与各段速度重算（Ctrl+Z 可撤销转换）。
- **粘贴**（Ctrl+V 到其他关卡的目标砖）时：新关卡 BPM 取目标砖前方（floor 更小）最近一个 SetSpeed 的生效值，按 `新BPM/源BPM` 等比缩放粘贴进来的 MoveDecorations 与 MoveCamera 的 `duration` 与 `angleOffset`（例：100→200 则两项 ×2）。同关卡内粘贴时比值为 1，不产生任何变化。

BPM 换算基于每砖的到达时间与生效速度（已计入 Twirl/Pause/Hold 影响的到达时间模型），与 MappingHelper 魔法阵"同步速度"的换算方式等价。

## 原生 bug 修复：真轨道增删时装饰锚点错位

游戏原生的 `OffsetFloorIDsInEvents` 平移事件/装饰锚点时条件是 `floor > start`（严格大于），导致：

- **加砖**：插砖位置上原有装饰的锚点漏移，粘到新加的砖上；
- **删砖**：被删砖上的装饰既没被移除也没被平移，粘到错误角度的砖上（对象装饰"错位/变形"）。

本模组在 `CreateFloor`/`DeleteFloor` 执行期间挂接该平移调用，把 `floor == start` 的砖块锚定装饰补齐（加砖随旧砖顺延、删砖随砖块移除并走游戏完整的 `RemoveEvents` 流程清理场景与列表面板），且完整处于游戏撤销作用域内（Ctrl+Z 一次还原）。对原生摆放的对象装饰同样生效。

## 原生 bug 修复：带轴心偏移的装饰无法点击

装饰视觉由两层嵌套子对象构成（positionOffset 层 + pivotOffset 层），而编辑器的拾取碰撞体只挂在根对象（floor + position）上。轴心偏移不为零的装饰（包括集中式生成的假轨道、以及手动摆放并设置轴心的装饰）的拾取点全部堆在锚点砖上：点击其他位置无法选中、点击锚点会循环选中全部。本模组在装饰创建与每次位置刷新后，把拾取碰撞体对齐到最深的视觉层，使点击判定与所见位置一致。

## 原生问题修复：装饰间叠放次序随刷新循环变化

游戏的装饰深度映射为：`depth < 0` 时渲染在 "Default" 层（在真砖块之前）、`depth ≥ 0` 时渲染在 "Bg" 背景层（在真砖块之后），层内排序序号为 −depth。层内序号相同（原生 sortingOrder 打平）的装饰之间，叠放次序由创建顺序决定——游戏每次刷新装饰（真轨道的任何更新都会触发重建）都会打乱它。

本模组完整保留原版的深度层与 −depth 序号、文字/粒子的 SpriteMask 范围、以及假轨道自己的内层序（描边、发光、图标等），不写任何 Renderer/Canvas/SpriteMask 的排序序号/层级/材质，也不改关卡数据；只给装饰的轴心 transform 加一个不超过 0.1 的距离偏移，用正交相机的远近**只**打破"原生序号打平"这一件事。偏移取自装饰在关卡装饰列表里的位置（`ratio = (列表序号 + 1) / (列表总数 + 1)`）：非假轨道占前半区、假轨道占后半区，z 越小越靠近相机、越压在上面 → 先摆放的压住后摆放的，图片/文字/粒子/星球压住同序号的假轨道（与原版类型优先一致）。偏移只由关卡数据决定，刷新不会改变 → 叠放永久稳定。开启"同步深度"（`syncFloorDepth`）的装饰继承父砖渲染参数、Prefab 装饰与玩家气泡结构特殊，三者都不参与。这条规则只用于打破原生平局，不承诺越过由原生序号决定的层次（例如假轨道描边与其相邻子渲染器之间的先后）。

## 使用提示

- 作用范围："被选中的砖块"（先选中地砖）或"特定范围"（按方块编号）。
- 生成动画必须先填 **tag**；生成的轨道装饰会同时携带 `tag` 与 `tag<编号>` 两个标签，动画事件按 `tag<编号>` 定位。
- 主标签留空时生成轨道，会打上保留前缀的自动标签 `_MultiTrack<编号>`；"重建前清除"始终会清理 `_MultiTrack` 前缀的旧结果，因此空标签生成同样可以幂等覆盖。
- 面板新增"深度"输入（默认 0）：本批全部假轨道与星球统一取该深度。游戏语义：正值在真轨道之后、负值在前。开启"深度递增"后改由初始深度/递增值逐块决定。
- 面板新增"生成位置"（XY 坐标，单位为方块，默认 0,0）：整批假轨道与星球整体偏移该坐标。
- 面板新增"多轨生成方式"（仅集中式布局可选，默认"位置"）：**位置**把轴心偏移折进每块假轨道的位置，各砖绕自己的中心自转/缩放；**轴心偏移**让所有假轨道的位置统一取"生成位置"，保留轴心偏移，旋转与缩放围绕这一个共用轴心（MappingHelper 的生成方式）。分布式布局每块假轨道绑定自己的砖，此选项置灰、不参与生成。选项旁的帮助按钮说明两种方式，选择集中式的"轴心偏移"后还会显示"共用轴心限制"提示。
- **轴心模式限制**：集中式布局选"轴心偏移"时，所有假轨道共用同一个轴心，与真砖逐砖自转、缩放的语义冲突，因此"同步移动轨道"会被自动关闭并置灰（此模式下不再复制 MoveTrack）。同步大小、透明度、风格、深度、星球、视差等支持的功能不受影响，禁用范围仅限这一个开关。改回"位置"或切到分布式后可手动重新开启。该收敛在面板变化与生成入口都会执行，仅影响新生成/重建的轨道，不会转换已有轨道，也不改变星球轨迹。
- 面板新增"同步大小"开关（默认关闭）：打开后逐砖读取真轨道的"星球半径大小"（ScaleRadius）事件，把它作为假轨道的大小；轴心偏移则折算回半径 100% 的数值，再由假轨道自身的 scale 放大回去，避免半径加倍时轴心偏移跟着成倍偏移。开启"改变平行"时以真轨道大小为基准做视差缩小。
- 面板新增"同步透明度"开关（默认关闭）：把真轨道的透明度逐砖同步给假轨道。真轨道透明度取自作用范围内的 `PositionTrack.opacity`（只在事件启用了 opacity 时生效；`justThisTile` 的只作用于该砖），所以和"轨道尺寸变化"里的"轨道位置透明度范围"是配套的。同步方式二选一，都直接写在生成的假轨道装饰上：**轨道主色调的透明度** → 改 `trackColor` 的 A 通道（颜色值写成 `#RRGGBBAA`，100% = FF 不透明、0% = 00 全透明）；**对象装饰本身的透明度** → 写 AddObject 的 `trackOpacity` 字段（对象面板里"轨道主色调"下面那个"透明度"，单位 %）。
- 面板新增"同步移动轨道"开关（默认开启，集中式 + 轴心偏移时自动关闭并置灰）：把作用范围内真轨道的 `MoveTrack` 转成逐砖的 `MoveDecorations`，复制启用的位置偏移、旋转、大小、透明度，以及时长、缓速和角度偏移。**分布式**副本沿用源砖，**集中式**自动触发副本统一挂在锚点砖并换算时序，保留绝对秒数；重复事件按原版规则展开，条件/撞击触发副本保留对应触发标签。自由漫游运行时生成的格子不在编辑器地砖列表内，不能完整同步，会在日志提示。
- 开启关卡全局的**粘性方块**（`stickToFloors`）后，星球跟随把基础星球轨迹与相位砖位移、旋转组合成姿态，再烘焙成分段 Linear 的 `MoveDecorations`；保留未被接管的其他属性。外部条件/撞击的触发时刻无法静态确定，不保证星球跟随烘焙覆盖这些触发。星球跟随没有单独开关，读取关卡设置。
- 面板的"同步轨道风格"与"同步移动轨道"独立：初始风格取对应真砖，后续 `RecolorTrack` 的风格变化转成只启用 `trackStyle` 的 `SetObject`，避免连带重置颜色、透明度和图标。
- 星球动画的"集中式"分布按 BPM 把每砖的动画对齐到第一个砖的角度轴上；"分布式"则每个砖挂自己的事件。
- 星球标签输入框留空时使用默认标签；主 tag 非空时默认是 `<tag>_BluePlanet`（保证不同批次星球互不干扰），输入后则完全以输入值为准。
- 在 UMM 管理面板里**开启/关闭本模组**时，会自动**重启关卡编辑器并重新载入当前关卡**（本模组在编辑器 Awake 时注入标签页与事件类型，只有重载才能干净地加上/去掉）。若当时有未保存改动，会先走游戏自带的"未保存"提示；取消则不会重载（mod 开关状态已生效，可再次切换）。
